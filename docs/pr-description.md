## Рішення щодо неоднозначностей

Описано в `docs/test-design.md`, розділ 2. Головне: максимум 4000 мг застосовується після зменшення вдвічі для дитинчат; вік у місяцях, дитинча — менше 36 міс.; NaN у вазі відхиляється.

