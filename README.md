# Драконяча клініка — ветеринарна клініка для вигаданих істот

Система для клініки, де лікують драконів, грифонів та інших вигаданих істот: картки пацієнтів, розклад прийомів і «вогнетривкі» процедури.

## Функції

- картки пацієнтів з видом істоти, віком і історією лікування
- розклад прийомів і запис до лікаря
- облік «вогнетривких» процедур та їхньої безпеки для персоналу
- нагадування власникам про повторні візити
